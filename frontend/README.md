# Frontend Module (Chainlit)

## Назначение
Веб-интерфейс для взаимодействия пользователя с RAG-системой. Предоставляет удобный чат, поддерживает стриминг ответов от Backend API и базовую аутентификацию.

## Внутренняя структура
* `app.py` — основное приложение Chainlit (обработчики `@cl.on_chat_start`, `@cl.on_message`).
* Взаимодействие с backend API осуществляется через HTTP-запросы (библиотека `httpx` или `aiohttp`).

## Авторизация и контекст
Система предусматривает аутентификацию (через встроенные механизмы Chainlit). При входе формируется профиль пользователя с указанием его прав доступа, которые затем передаются в Backend API для фильтрации поиска.

### Структура User Context (пример профиля пользователя в сессии)
```python
{
    "user_id": "string",
    "username": "string",
    "roles": ["HR", "Engineering"], # Права доступа для чтения определенных документов
    "department": "Engineering"
}
```

### Формирование запроса к API
При отправке вопроса интерфейс автоматически подставляет параметры пользователя в тело запроса:
```python
request_payload = {
    "query": message.content,
    "top_k": 3,
    "filters": {
        "allowed_roles": user_roles # Берется из сессии
    },
    "stream": True
}
```
