# Data Models (`app/models`)

## Назначение
Pydantic-модели (DTO — Data Transfer Objects) для описания контрактов данных между слоями приложения и внешней средой (API, БД).

## Ожидаемая структура
* `__init__.py`
* `api.py` — Модели для эндпоинтов HTTP (например, `QueryRequest`, `QueryResponse`, `SourceDocument`).
* `domain.py` — Внутренние модели домена (метрики, конфигурации, промежуточные структуры для сервисов).

## Правила написания кода
- **OpenAPI Ready:** Обязательное использование `Field(..., description="...")` для всех полей, чтобы FastAPI мог автоматически генерировать качественную Swagger-документацию.
- **Validation:** Строгая валидация типов и значений (например, ограничения на длину запроса, допустимые диапазоны `top_k`).
- **Encapsulation:** Если модель требует сложной валидации (например, зависимости одного поля от другого), использовать декораторы `@model_validator`.
