# Core Configuration (`app/core`)

## Назначение
Ядро приложения, содержащее глобальные конфигурации окружения (`.env`), инициализацию сторонних клиентов (LLM, Embeddings, БД) и системные настройки (промпты, логирование).

## Ожидаемая структура
* `__init__.py`
* `config.py` — Парсинг переменных окружения с помощью `pydantic-settings` (API-ключи, URL векторной БД, названия моделей).
* `llm.py` — Инициализация синглтонов (Singletone) для LlamaIndex, LLM (Qwen3) и Embeddings.
* `prompts.py` — Строковые шаблоны или объекты для системных промптов (System Prompts, Context QA Templates).
* `logger.py` — Настройки логирования (формат, уровни вывода, структурированные JSON-логи для продакшена).

## Правила написания кода
- **Security First:** Никаких захардкоженных секретов. Любые URL и токены берутся строго из `config.py`.
- **Global State:** Компоненты LlamaIndex и Qdrant инициализируются один раз при старте приложения (через lifespan events FastAPI) для экономии ресурсов.
